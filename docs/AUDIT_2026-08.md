## 2. Findings, ranked

### Trust / compliance (rank 1)

1. **[confirmed] The linter was inoperable on the founder's OS** (encoding
   crash + `python3` alias). Practical effect: the strictest gate in the system
   could not have been part of any run performed on this machine. Fixed;
   `selfcheck.py` pins it.
2. **[confirmed] Two docs still taught pre-v4 regulatory wording.**
   `WHATSAPP_AGENT_BRIEF.md` §2/§3/§5 instructed the bot to *answer* with a
   certification phrase; `TWO_MARKET_RESEARCH_SETUP.md` §3 explained which
   regulatory phrasing to prefer. Both contradict the total ban (COPY_RULES §4)
   and the deployed bot design (certification questions escalate, always).
   Corrected to point at COPY_RULES.
3. **[confirmed] The masters are heavily-compressed JPEGs misnamed `.png`**
   (980×1232, ~50 KB). Upscaled ~2.2× at render; erasure ghosting (pink smears
   where old text was removed) is visible on final rendered cards. This is a
   founder item: re-export clean masters at 2160×2700 from the original design
   files. Layout stays LOCKED — this is the same artwork, cut properly.
4. **[confirmed] Cheap-model imagery risk lives website-side, not here.** This
   repo calls no image model (grep-verified). The flywheel drafts card art on
   the cheap tier and re-renders on the flagship only after approval; nothing
   currently stops a draft-tier image from publishing if that ordering breaks,
   and one registered model is labeled for "people / lifestyle scenes", which
   collides with the no-AI-people rule. → Proposals §1–2. Policy written into
   CLAUDE.md here.
5. **[still open — founder]** Rotate `CONTENT_INGEST_SECRET` (README carries
   the exposure note). Operational, coordinated with the website agent
   (Proposals §6). The secret was never printed or written during this audit;
   mock rehearsals used a synthetic value.

### Weekly-run reliability (rank 2)

6. **[confirmed, fixed]** `OK` did not require `status == "needs_review"`, and
   a contract break still exited 0. Now: any unexpected status → `ERROR` +
   non-zero exit. Proven against the mock.
7. **[confirmed, fixed]** An HTTP-error response whose body could not be read
   (server rejecting a large upload mid-flight) crashed the sender with a raw
   traceback — found live in rehearsal (401 against a 1.2 MB POST). Guarded.
8. **[confirmed, fixed]** The generic exception path retried errors like
   `RemoteDisconnected` where the request may already have been processed —
   the exact blind-retry duplication the docs warn about. Retry now limited to
   provably-never-sent failures (connection refused, DNS); everything
   uncertain returns the "MAY already be stored" path.
9. **[confirmed]** The website's duplicate-insert race (`findCardId`) was fixed
   2026-08-09, so re-sending after a timeout supersedes in place. Stale
   warnings in CLAUDE.md / sender messages updated. **[inferred]** the deployed
   worker includes the fix (merge recorded in website docs; deployment itself
   not verifiable from here — confirmation asked in Proposals §5).
10. **[confirmed, fixed]** Instagram-JPEG open item closed end to end: renderer
    emits JPEG alongside PNG; sender ships the JPEG (site sniffs bytes and
    derives the extension; its IG publisher refuses `.png` paths). Bonus:
    payloads dropped ~60%.

### Simplification (rank 3) — see keep/fix/kill table §3

Net: one file deleted (Word lock litter), zero new frameworks; the four files
added are each a used blade (regression gate, rehearsal server, scoreboard +
appender) and three of them were already promised by the docs or the v3
workflow anyway.

### Growth enablers (rank 4)

12. **[confirmed]** Step 0's best input (real WhatsApp questions) is

13. **[confirmed]** Video/TikTok: ingest cannot carry a `format` today (DB
